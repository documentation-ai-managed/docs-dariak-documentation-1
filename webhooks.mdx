## Webhooks Overview

Webhooks in Dariak allow you to receive real-time notifications about documentation events. This enables you to build automated workflows and integrations with other tools.

<Callout kind="info">
  Webhooks deliver events as HTTP POST requests to your specified endpoint.
</Callout>

## Setting Up Webhooks

Configure webhooks in your Dariak dashboard to start receiving events.

<Steps>
  <Step title="Access Settings" icon="settings">
    Navigate to your project settings and select the Webhooks tab.
  </Step>
  <Step title="Create Webhook" icon="plus">
    Click "Add Webhook" and provide your endpoint URL.
  </Step>
  <Step title="Select Events" icon="check-circle">
    Choose which events you want to receive notifications for.
  </Step>
  <Step title="Configure Security" icon="shield">
    Set up webhook signatures for security verification.
  </Step>
</Steps>

## Security and Verification

Ensure webhook deliveries are legitimate using signature verification.

<CodeGroup tabs="Node.js,Python">
  ```javascript
const crypto = require('crypto');

function verifySignature(payload, signature, secret) {
  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(payload, 'utf8')
    .digest('hex');
  return `sha256=${expectedSignature}` === signature;
}
```
  ```python
import hmac
import hashlib

def verify_signature(payload, signature, secret):
    expected = hmac.new(
        secret.encode('utf-8'),
        payload.encode('utf-8'),
        hashlib.sha256
    ).hexdigest()
    return f'sha256={expected}' == signature
```
</CodeGroup>

<Callout kind="danger">
  Always verify webhook signatures to prevent malicious requests to your endpoints.
</Callout>

## Best Practices

Follow these guidelines for reliable webhook integrations.

<Callout kind="tip">
  Respond to webhook requests within 10 seconds to avoid timeouts.
</Callout>

- Process webhooks asynchronously to avoid blocking
- Store webhook data for debugging and auditing
- Implement proper logging for webhook activities
- Use webhook signatures for security verification
- Handle duplicate deliveries gracefully
- Monitor webhook delivery success rates
