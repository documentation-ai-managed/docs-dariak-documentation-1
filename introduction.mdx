## Key Features

Dariak provides a comprehensive platform for documentation management. You can create interactive guides, generate API references automatically, and collaborate with your team in real-time.

<Tabs>
  <Tab title="For Developers" icon="code">
    Build robust documentation with our developer-friendly tools. Use our SDK to integrate documentation directly into your CI/CD pipeline.
    
    <CodeGroup tabs="JavaScript,Python">
      ```javascript
const dariak = require('dariak-sdk');

const doc = await dariak.create({
  title: 'API Guide',
  content: '# Welcome to our API'
});
console.log('Document created:', doc.id);
```
      ```python
from dariak_sdk import Dariak

dariak = Dariak(api_key='your_key')
doc = dariak.create_document(
    title='API Guide',
    content='# Welcome to our API'
)
print(f'Document created: {doc.id}')
```

## Use Cases

Dariak is perfect for various scenarios:

- **API Documentation**: Automatically generate comprehensive API docs from OpenAPI specifications
- **Product Guides**: Create interactive tutorials and user manuals
- **Knowledge Bases**: Build searchable internal wikis for your organization
- **Developer Portals**: Host public documentation with custom branding

<ExpandableGroup>
  <Expandable title="API Documentation Example" default-open="false">
    Generate detailed API documentation with interactive examples.
    
    ```javascript
const apiDoc = await dariak.generateApiDoc({
  spec: 'openapi.yaml',
  theme: 'dark',
  interactive: true
});
```
  </Expandable>
  <Expandable title="Product Guide Creation" default-open="false">
    Build step-by-step guides with embedded media and code samples.
    
    ```python
guide = dariak.create_guide(
    title='Getting Started',
    steps=[
        {'title': 'Install', 'content': 'npm install dariak'},
        {'title': 'Configure', 'content': 'Set up your API key'}
    ]
)
```
  </Expandable>
</ExpandableGroup>
