## Theme Configuration

Customize the appearance of your documentation with built-in themes and custom styling.

<Tabs>
  <Tab title="Light Theme" icon="sun">
    Clean and bright theme for daytime use.
    
    ```json
{
  "theme": "light",
  "colors": {
    "primary": "#3B82F6",
    "background": "#ffffff"
  }
}
```
  </Tab>
  <Tab title="Dark Theme" icon="moon">
    Easy on the eyes for extended reading.
    
    ```json
{
  "theme": "dark",
  "colors": {
    "primary": "#60A5FA",
    "background": "#1f2937"
  }
}
```
  </Tab>
</Tabs>

<Callout kind="tip">
  Use custom CSS variables to override default theme colors for complete branding control.
</Callout>

## Environment Variables

Use environment variables for sensitive configuration.

| Variable | Description | Required |
|----------|-------------|----------|
| `DARIAK_API_KEY` | Your API key | Yes |
| `DARIAK_BASE_URL` | API base URL | No |
| `DARIAK_THEME` | Default theme | No |

<CodeGroup tabs="Linux,macOS,Windows">
  ```bash
export DARIAK_API_KEY="your_key_here"
export DARIAK_BASE_URL="https://api.dariak.com"
```
  ```bash
export DARIAK_API_KEY="your_key_here"
export DARIAK_BASE_URL="https://api.dariak.com"
```
  ```cmd
set DARIAK_API_KEY=your_key_here
set DARIAK_BASE_URL=https://api.dariak.com
```
</CodeGroup>

<Callout kind="info">
  Environment variables take precedence over configuration file settings.
</Callout>
